# ml-turnstile — releases

Repositório público somente com os pacotes oficiais (ZIP) do plugin **ml-turnstile**, da ML Lopes Design.

O plugin instalado no WordPress consulta este repositório para oferecer atualizações automáticas. O código-fonte fica em um repositório privado.

Cada versão publica um único arquivo: `ml-turnstile-vX.Y.Z.zip`.
